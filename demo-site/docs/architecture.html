Architecture of a polite crawler

Breadth-first, one level at a time

The crawler finishes every page of one depth before it admits the next depth, so each page gets its shortest distance from the seed, whatever the number of workers.

Leases and fencing tokens

A worker claims a URL with a lease. If the lease expires, another worker can take the URL over with a new fencing token, and the late result of the first worker is rejected.

Politeness

Requests to one host are spaced out, and robots.txt is obeyed. See the glossary and the blog post on crawling politely.
